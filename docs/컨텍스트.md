# 과목 컨텍스트 관리 상세 · 제작 지침 v2.3 별책 (kit/docs/컨텍스트.md)

> 제작 지침 v2.2의 7-3(머리말 · 명령 다섯)과 부록 B 「03 편집(`ctx_edit.py`)」를 **글자 그대로** 옮긴 것이다(v2.3에서 매 턴 읽히는 본체를 줄이려고 — 동작·규칙은 그대로). 7-3의 명령을 받았을 때와 그 밖에 03을 고칠 때(Step 0의 교수표 행 · Step 4 · 기출정리 · 2차병합)만 읽는다. 7-3의 「캡처(이미지) 판독 규칙」은 기출 전사에도 쓰이므로 본체 7-3에 남았다 — 이 파일의 「아래 판독 규칙」 · 「같은 규칙」은 그것을 가리킨다.

### 7-3. 과목 컨텍스트 관리 (03을 Claude가 고치는 경우)
03은 지식의 `컨텍스트/03_[과목].md`가 원본이다. 어떤 명령이든 **`ctx_edit.py`로 행만 바꾸고 `check`를 통과한 파일만 교체**한다(6장 12). 바뀐 뒤 채팅에는 바뀐 행(또는 수치)과 확인 필요 표만 적고 파일은 보여 주지 않는다. 지식 쓰기가 없으면 고친 03을 제시하고 교체를 부탁한다.

- `컨텍스트 등록` (+ 03 파일, 과목당 1회): 03 틀의 1절을 채운 파일을 받아 `check` → 지식 `컨텍스트/03_[과목].md`. 과목명은 파일 제목 `# [과목] 과목 컨텍스트`에서 읽고, 제목이 틀 그대로면 1절의 「학기 · 과목」에서 읽어 제목도 고친다. 둘 다 없으면 묻는다.
- `교수표 정리` (+ 올해 시간표 캡처): 캡처를 아래 판독 규칙으로 읽어 TSV(주차 · 수업일 · 담당 교수 · 강의명(있으면) · 비고)를 만들고 `prof-bulk`로 2절에 넣는다. 보고: "캡처 n장 · 읽은 행 m · 확실 a · 확인 필요 b → 교수표 갱신 x · 추가 y" + 확인 필요 표(있을 때만).
- `담당 이력 정리` (+ 작년·재작년 시간표 캡처): 같은 규칙으로 읽어 TSV(주제 = 그해 강의명 그대로 · 연도별 교수)를 만들고 `history-bulk`로 2-2에 넣는다. 연도는 캡처에 보이는 것을 쓰고, 안 보이면 **먼저 묻는다**(03 1절의 학기로 추정하지 않는다). 주제명은 **작년(가장 최근 연도) 강의명**이고, 그보다 앞선 연도에서 글자가 다른 이름은 「이전 명칭」에 둔다(그래야 같은 주제가 둘로 갈라지지 않는다).
- `교수표 업데이트 [주차·날짜] [강의명] [교수] [대응 기출 주제]`: 글로 받은 값을 `prof`로 넣는다(대응 행은 강의명 → 수업일 → 주차 순으로 찾는다). 대응 기출 주제를 비워 두었으면 강의명·교수와 2-2를 대조해 **후보를 제시하고 확인을 받은 뒤** 넣는다(추측으로 채우지 않는다 — 7-1의 10). 강의자료 파일명을 알려 주면 비고에 적는다.
- `학기 설정`: 등록 → 교수표 정리 → 담당 이력 정리를 차례로 하고 확인 요청을 끝에 한 번에 모은다. 기출정리는 파일 단위로 따로 돌린다(한 채팅에 한두 파일).
- 03의 다른 절은 각 명령이 쓴다: 2-1 표기 사전·2-2 기출 파일 칸(기출정리), 4절 용어집(2차병합·보정 마감), 3절 관찰 메모·2절 학습자료 칸(Step 4). 5절 약점 로그와 3절 적중률은 복습 프로젝트의 몫이다.

## 부록 B 중 「03 편집(`ctx_edit.py`)」

**03 편집(`ctx_edit.py`)** — 파일을 통째로 다시 쓰지 않고 행만 바꾼다. 쓰기 전후로 `check`.
```
python3 kit/ctx_edit.py check work/in/03_[과목].md
python3 kit/ctx_edit.py prof-bulk work/in/03_[과목].md work/[작업]/rows.tsv        # 교수표 정리 (머리: 주차 수업일 담당교수 강의명 대응기출주제 비고 — 있는 열만)
python3 kit/ctx_edit.py history-bulk work/in/03_[과목].md work/[작업]/rows.tsv     # 담당 이력 정리 (머리: 주제 이전명칭 2025 2024 2023 이전 기출파일)
python3 kit/ctx_edit.py prof work/in/03_[과목].md --date 09-10 --lecture "당신생" --prof 박OO --topic "해당과정의 조절"   # 교수표 업데이트
python3 kit/ctx_edit.py prof work/in/03_[과목].md --lecture "[강의명]" --material 완료                                  # Step 4
python3 kit/ctx_edit.py profile work/in/03_[과목].md --prof 김OO --line "…관찰 메모 한 줄…" --tag "[강의명] · 09-10"   # Step 4
python3 kit/ctx_edit.py alias work/in/03_[과목].md --mark "김T" --prof 김OO                                             # 기출정리
python3 kit/ctx_edit.py history work/in/03_[과목].md --topic "[주제]" --exam-file "기출_[과목]_[주제].md"               # 기출정리
```
고친 파일을 지식 `컨텍스트/03_[과목].md`에 쓴다(교체).
