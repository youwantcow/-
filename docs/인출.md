# 인출 노트 — 제작 지침 v3.1 (Step 4의 5 · `인출 [강의명]`)

학습자료(HTML)는 **이해**하는 자료다. 인출 노트는 그 뒤에 Obsidian에서 **꺼내는** 자료다. 같은 내용을 읽기 좋게 한 번 더 옮긴 사본은 만들지 않는다 — 두 번 읽는 것에 그친다(2026-11-16 시범에서 사용자가 확인).

Obsidian이 HTML과 갈리는 것은 셋뿐이고, 인출 노트는 이 셋에 기댄다.

1. 기록이 파일에 남고 기기 사이에 따라온다 → 반복 플러그인(Spaced Repetition, 개발자 st3v3nmw)이 날짜를 두고 다시 낸다
2. 사용자가 고칠 수 있다 → 틀린 자리에 형광펜을 치면 그게 빈칸이자 카드가 된다
3. 강의를 넘어 모인다 → 덱이 `과목 › 강의 › 층`으로 쌓인다

## 1. 언제 · 무엇으로

- 전 Part가 끝나고 **병합본이 나온 뒤**(Step 4). 재료는 병합본 HTML 하나와 강의자료 PDF.
- 병합본은 **지침 v2.7 이상**으로 만든 것이어야 재료가 다 나온다(먼저 풀어 보기 · 빈칸 인출 · 방향 사슬 · 개념 카드 · 퀴즈 · 변형 예측 문제). 그 전 판도 돌아가지만 개념 카드 · 표의 줄 · 퀴즈가 0으로 나온다 — 그 사실을 보고에 적는다.
- 뼈대(Step 4의 4)를 만들었으면 캔버스를 함께 넣는다(`map_kit.py canvas` → `--canvas`).
- **한 강의에 한 번만** 만든다. 복습 기록과 사용자가 더한 빈칸이 노트 안에 저장되므로, 다시 만들면 지워진다. 이미 준 강의를 다시 만들어 달라고 하면 그 사실을 먼저 알리고 확인을 받는다.

## 2. 명령

```
python3 kit/recall_kit.py build work/out/[과목]_[강의명]_전체.html --pdf "work/in/[강의자료].pdf" --first 1 \
        --lecture [강의명] --subject [과목] [--canvas work/out/[과목]_[강의명]_뼈대.canvas] -o work/obsidian/[과목]
python3 kit/check_recall.py work/out/[과목]_[강의명]_전체.html work/obsidian/[과목] --lecture [강의명] --pages [PDF 쪽수]
python3 kit/recall_kit.py pack work/obsidian/[과목]/[강의명] -o work/out/인출_[과목]_[강의명].zip [--first-time]
```

- `--lecture`는 파일 이름과 덱 이름에 쓰인다. **띄어쓰기 없이**(태그에 공백이 못 들어간다) — 예: `Intro1-1` · `유전자발현조절2`.
- `--first`는 PDF 1쪽의 원본 쪽번호(Part 빌드 때와 같은 값).
- `--first-time`은 그 사용자에게 인출 노트를 처음 줄 때만 — 스니펫 `recall.css`와 「00 인출 노트 시작하기」가 zip에 함께 들어간다.
- `build`의 세 줄(「인출 노트: …」 · 「재료: …」 · 「링크: …」)과 △ 줄, `check`의 네 줄과 「검사 통과」, `pack`의 한 줄을 채팅에 그대로 옮긴다. `check`가 ✕를 내면 zip을 제시하지 않고 원인을 보고한다.

## 3. 나오는 것 — 강의 하나 = 폴더 하나

```
[강의명]/
  [강의명] 길잡이.md        첫 화면 — 순서 · 카드 수 · Part별 링크
  [강의명] 1 흐름.md        강의 전체 → Part → 절 순서 → 방향 사슬          덱 flashcards/[과목]/[강의명]/1-흐름
  [강의명] 2 개념.md        대표 질문 · ★ · 개념 카드 · 함정 · 표의 줄 · 인출 연습   덱 …/2-개념
  [강의명] 3 기출.md        동일 교수 기출 → 그 밖의 기출 → 변형 예측 → 퀴즈       덱 …/3-기출
  [강의명] 4 표와 쪽.md     빈칸 인출 표 · 혼동 쌍 표 · 쪽 제목만 보고 말하기    카드 아님(가림만)
  [강의명] 뼈대.canvas      (--canvas를 줬을 때)
  첨부/[강의명]_강의자료.pdf · [강의명]_기출그림_NN.jpg
```

사용자는 이 폴더를 보관함의 **과목 폴더 안에 끌어다 놓기만** 한다. 파일 이름이 전부 강의명으로 시작해서 다른 강의와 섞이지 않고, 링크는 이름으로 걸려 있어서 폴더를 어디로 옮겨도 살아 있다.

```
(보관함)/인출 연습/
  00 인출 노트 시작하기.md
  분자생물학/
    Intro1-1/ …
    Intro1-2/ …
  생화학/
    유전자발현조절2/ …
```

## 4. 재료가 어디로 가나

| 학습자료의 것 | 인출 노트에서 | 노트 |
| --- | --- | --- |
| 큰 그림(질문 · 흐름 · 연결) · 절 제목 · 방향 사슬 | 묻고 답하기 | 1 흐름 |
| 먼저 풀어 보기 · 인출 연습 | 질문 → 가린 답 | 2 개념 |
| 1순위 박스(출제 언급 · 자세히 설명 · 반복 출제) | ★ 「한 줄 결론과 그 이유는?」 · 「시험에서는 어떻게 묻나?」 | 2 개념 |
| 개념 카드(--pack) | 「정의는?」 · 「요점 n가지는?」 · 「자주 혼동되는 점은?」 | 2 개념 |
| [놓치기 쉬운 포인트] · [예상 출제 포인트] | 「무엇을 조심하라는 거지?」 · (AI 추정) | 2 개념 |
| 빈칸 인출 표 | **한 줄 = 한 장**(가려지지 않은 칸이 단서) | 2 개념 |
| 빈칸 인출 표 · 혼동 쌍 표 그대로(recall_kit v1.2: `<h3>혼동 쌍 …</h3>` + 표 · 박스 · 표만 — 세 모양 모두, 표 뒤 「읽는 법」 문단까지) | 가림표 | 4 표와 쪽 |
| 기출 · 변형 예측 문제 · 퀴즈 | 문제 → 접힌 「답 · 해설」 | 3 기출 |
| 쪽별 핵심 요약 · [그림 해설] · [표 해설] | 쪽 제목 → 접힌 내용(슬라이드 굵은 글씨 · 차이 칸은 한 번 더 가림) | 4 표와 쪽 |

싣지 않는 것: 쉬운 설명 · 본문의 ⚠ 플래그 · 판단 근거 · 강의록 인용 · 라벨 칩 — 이해와 근거는 학습자료에 있다.

## 5. 지키는 것

- **새 사실을 만들지 않는다.** 덧붙이는 것은 질문 틀(「정의는?」 같은 문장)뿐이다. `check`의 「노트 → 원본」이 이를 센다.
- **실선과 점선을 섞지 않는다.** 변형 예측 · 예상 출제는 제목에 (AI 추정)이 붙는다.
- 표를 통째로 빈칸 카드로 만들지 않는다 — 한 칸만 가리면 다른 칸이 답을 알려 준다.
- 태그가 붙은 노트(1 · 2 · 3)에 `==형광펜==`을 넣지 않는다(답 줄 안은 예외 — 묻고 답하기 카드의 답은 빈칸 카드가 되지 않는다). 사용자가 「내가 더한 것」에 넣는 형광펜만 빈칸 카드가 된다.
- 카드 한 장은 빈 줄 없이 붙어 있어야 한다(질문 줄들 / `?` / 답 줄들). 노트를 손으로 고칠 일이 있으면 이 모양을 깨지 않는다.
- `recall_kit.py` · `check_recall.py` · `recall.css`를 고치지 않는다. 노트를 손으로 쓰지 않는다.
- 플러그인 파일은 넣지 않는다 — 사용자가 Obsidian 안에서 설치한다(설정 → 커뮤니티 플러그인 → `Spaced Repetition`, 개발자 st3v3nmw).

## 6. 채팅에 적을 것

스크립트 출력 줄 + 사용자가 할 일 두 줄:

1. zip을 풀어 `[강의명]` 폴더를 보관함의 과목 폴더에 끌어다 놓는다(처음이면 `recall.css`를 스니펫 폴더에 넣어 켜고 플러그인을 설치한다 — 「00 인출 노트 시작하기」 2 · 3번).
2. 이 노트는 다시 만들지 않는다 — 한 번 받은 뒤로는 사용자의 노트다.

확인하지 못하는 것(Obsidian과 플러그인 화면에서의 실제 모습)은 확인했다고 쓰지 않는다. 검사가 본 것은 링크 대상 · 원본 대조 · 카드 모양이다.
