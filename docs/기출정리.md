# 기출정리 상세 · 제작 지침 v2.3 별책 (kit/docs/기출정리.md)

> 제작 지침 v2.2의 7-1(머리말 · 1~9)과 부록 B 「기출정리(`exam_tools.py`)」를 **글자 그대로** 옮긴 것이다(v2.3에서 매 턴 읽히는 본체를 줄이려고 — 동작·규칙은 그대로). `기출정리` · `기출정리 반영` 때만 읽는다. 7-1의 10 「학기 중 연결」은 제작에도 쓰이므로 본체 7-1에 남았고, 스캔본 전사에는 본체 7-3의 「캡처(이미지) 판독 규칙」이 그대로 적용된다. 이 파일 안의 「6장」 「2-1」 「2-2」 같은 참조는 본체 지침과 03을, 「부록 B」는 이 파일 아래쪽 절을 가리킨다.

### 7-1. `기출정리` 상세
학기 초에 파일 단위로 여러 번, 학교 기출 파일이 갱신되면 그 파일만 다시 돌린다. 입력은 첨부된 기출 파일(PDF — 한글·워드 파일은 PDF로 내보내서)과 과목 컨텍스트의 **주제별 담당 이력(2-2)** · 기출 교수 표기 사전(2-1)이다. 기계적인 일(원문 자르기 · 그림 자르기 · 조립 · 대조)은 `exam_tools.py`가 하고(부록 B), Claude는 문항 경계·교수·주제·그림을 판단해 **배정표**를 쓴다. 원문을 다시 타이핑하는 일은 없다.

**배정 단위는 올해의 강의가 아니라 주제다.** 올해 강의명은 학기 중에 한 주씩 확정되므로, 기출은 이전 연도 강의 단위의 주제(2-2의 주제명 = 작년 강의명)로 정리해 두고, 올해 강의와의 연결은 교수표의 「대응 기출 주제」 칸이 맡는다(10). 2-2가 비어 있으면 기출 파일의 구분 · 표기와 사용자가 첨부한 이전 연도 강의 목록으로 주제 목록 초안을 만들어 확인을 요청하고, 확인 전까지는 교수를 추정하지 않는다(확정 아니면 미상).

1. **원문 보존.** 발문 · 선지 · 답 · 근거를 한 글자도 바꾸지 않는다(오탈자도 그대로 — 고치는 것은 제작 단계의 일이다). `extract`로 뽑은 글자를 줄 번호로 잘라 옮긴다. 스캔본이라 글자가 없으면(`extract`가 알린다) 쪽 이미지를 보고 옮겨 적되 파일 머리에 「전사본」이라고 적고, 읽기 불확실한 곳은 [판독 불가].
2. **문항 분리와 고정 ID.** `연도-차수-번호`(예: 24-1-17), 번호가 없으면 `연도-차수-Q순번`. 구역마다 번호가 1부터 다시 시작하면 구역 표시를 끼운다(예: 22-1-박3, 23-2-주-김명곤-1). 한 번 붙인 ID는 이후 갱신 때도 바꾸지 않는다.
   - 같은 시험의 같은 문항을 여러 학생이 복기했으면 한 ID 아래 「복기본 A / B」로 모두 싣는다. 합치거나 하나를 고르지 않는다.
   - 다른 연도에 같은 문제가 다시 나왔으면 ID를 따로 두고 서로 「재출제: 22-1-5」로 잇는다(`stems`로 이번 파일의 발문을 뽑고, 이전 정리의 문항은 지식의 주제별 파일·색인에서 같은 발문을 찾는다).
3. **교수 표기 정리** — 주제 배정과는 별개의 축이다. 교수가 정해지지 않아도 주제 배정은 그대로 한다.
   - (a) 원표기는 항상 그대로 남긴다(문항 머리나 구역 제목의 `[○○ 교수님 …]`은 다음 교수 제목이 나올 때까지 그 아래 문항들에 적용된다).
   - (b) **확정**: 과목 컨텍스트의 교수 목록 · 기출 교수 표기 사전과 대조해 한 사람으로만 해석될 때(예: "김T"인데 이 과목의 김씨 교수가 한 명뿐).
   - (c) **추정**: 해석이 둘 이상이거나 표기가 없지만, **그 연도에** 그 주제를 누가 맡았는지 주제별 담당 이력(2-2)으로 알 수 있을 때. 근거를 한 줄 적는다(예: "2023년 해당과정 담당 = 김OO"). 다른 연도의 이력으로는 추정하지 않는다(미상으로 두고 후보만 적는다).
   - (d) **미상**: 둘 다 안 될 때. 추측하지 않는다.
4. **주제 배정.** 교수 표기가 아니라 문항이 묻는 핵심 개념이 어느 주제의 내용인지로 정하고, 근거를 한 줄 적는다(핵심 키워드 → 주제). **그 문항이 중간·기말 어느 시험에 나왔는지, 기출 파일의 어느 구역·순서에 있는지는 배정 근거로 쓰지 않는다** — 교육과정 순서와 시험 범위는 해마다 바뀌므로 작년 기말 문항이 올해 중간 범위일 수 있다. 시험 차수는 ID와 색인에 기록으로만 남는다. 주제명이 연도에 따라 달리 불렸으면 2-2의 「이전 명칭」으로 같은 주제로 본다.
   - 두 주제 이상에 걸치면 **관련된 모든 주제 파일에 전문을 싣고** `공통: [주제]·[주제]`로 표시한다. ID는 하나다. 선지 하나만 다른 주제에 걸치는 정도는 공통이 아니다 — 정답을 고르는 데 두 주제의 내용이 모두 필요할 때만 공통으로 한다.
   - 근거가 부족해 어느 주제인지 판단할 수 없거나 주제 목록에 없는 내용이면 억지로 배정하지 않고 `미분류`에 이유와 후보 주제를 둔다.
5. **그림.** 복기본에 그림(구조식 · 경로 · 그래프 · 사진 · 염기서열)이 들어 있으면 그 그림을 **문항별로 잘라** 둔다.
   - `figs`가 쪽마다 그림 후보(래스터 이미지는 자동으로 잘라 둠, 벡터 도형이 많은 쪽은 알림)를 보고하면, 후보 쪽과 발문에 "그림 · 구조 · 다음 중"이 있는 쪽을 `pages --grid`로 렌더해 **직접 보고** ① 어느 문항의 그림인지 ② 자동 추출본을 그대로 쓸지, 눈금을 읽어 `crop`할지 정한다. 그림 하나 = 파일 하나(`ID.png`, 둘이면 `ID_2.png` — 배정표 그림 칸에 `ID.png;ID_2.png`처럼 `;`로 잇는다). 문항 번호·발문이 같이 잘려 들어가도 된다(그림만 억지로 떼어 내지 않는다).
   - 그림이 있어야 하는 문항인데 복기에 그림이 없으면(발문만 "다음 구조식 중…") 배정표 그림 칸에 `누락`.
   - `assemble`이 그림들을 한 장에 하나씩 `기출그림_[과목].pdf`로 모으고 문항 블록·색인에 `〔그림 n〕`을 적는다. **두 번째 정리부터는 기존 `기출그림_[과목].pdf`를 `--prev-figpdf`로 주어 뒤에 이어 붙인다**(쪽 번호가 바뀌면 이미 만든 학습자료의 그림이 어긋난다). 기존 PDF가 세션에 없으면(프로젝트 파일에 있으면 내려와 있다) 첨부를 요청하고 멈춘다.
6. **배정표(TSV)**를 파일마다 쓴다(열은 부록 B). 시작줄은 문항 번호가 있는 줄, 끝줄은 그 문항의 마지막 줄(답·근거가 붙어 있으면 그것까지). 쪽 표시 줄이 문항 중간에 끼어 있으면 범위에 그냥 둔다. 문항이 아닌 줄(시험 제목 · 안내문 · 구역 제목)은 어느 행에도 넣지 않는다. 끝에 파일의 문항 번호를 다시 세어 빠진 것이 없는지 맞춘다.
7. **조립과 지식 쓰기.** 지식에 `기출_[과목]_색인.md`가 없으면 첫 정리(`assemble`), 있으면 두 번째부터(`--append`). `--append` 전에 이번 배정표에 나온 주제의 기존 `기출_[과목]_[주제].md`와 `…_색인.md` · `…_미분류.md`를 지식에서 내려 출력 폴더에 둔다(이 파일들에 기존 문항이 들어 있다 — 내려 두지 않은 주제의 문항은 대조 보고에 「미검증」으로 따로 센다). 같은 기출 파일을 다시 정리할 때는 이전 정리와 같은 ID·같은 그림 파일 이름을 쓴다(ID가 바뀌면 옛 블록이 남고, 그림을 다시 자르면 기출그림 PDF 끝에 또 붙는다). 출력 파일(주제별 · 미분류 · 색인)을 지식 `기출/`에 쓰고(같은 이름이면 교체), 새로 알게 된 표기는 `ctx_edit.py alias`로 2-1에, 주제별 파일명은 `history --exam-file`로 2-2의 「기출 파일」 칸에 넣어 03을 교체한다. `기출그림_[과목].pdf`는 **다운로드로 제시**하고 "제작·복습 프로젝트의 프로젝트 파일에 올려 달라(있으면 교체)"고 적는다 — 이것만은 Claude가 지식에 쓸 수 없다.
8. **대조 보고(채팅).** `assemble` 출력을 그대로 옮긴다: 「원본 N = 단독 배정 a + 공통 b + 미분류 c」「주제별 파일 문항 수 합계 = a + (공통 문항의 배정 횟수 합)」「그림 있음 n · 누락 m · 기출그림 PDF 총 k쪽」. 맞지 않으면 어디서 어긋났는지 찾아 고친 뒤 보고한다. 수치 없는 "전부 정리함" 선언은 금지.
9. **확인 요청.** `추정` · `미상` 교수 목록과 `미분류` 목록, 그림이 어느 문항 것인지 애매했던 것을 한 번에 묻는다(각각 후보와 근거 포함). 답을 받으면 `기출정리 반영`으로 배정표를 고쳐 다시 조립하고 지식의 파일을 교체한다.

(10 「학기 중 연결」은 본체 7-1에 있다.)

## 부록 B 중 「기출정리(`exam_tools.py`)」

**기출정리(`exam_tools.py`)** — 7-1의 순서대로.
```
python3 kit/exam_tools.py extract work/in/기출_2024_a.pdf --out work/exam/기출_2024_a.txt      # 글자 (2단이면 열 순서로)
python3 kit/exam_tools.py number  work/exam/기출_2024_a.txt --out work/exam/기출_2024_a.num.txt # 줄 번호
python3 kit/exam_tools.py figs    work/in/기출_2024_a.pdf --out work/exam/figs                   # 그림 후보 쪽 + 자동 추출
python3 kit/exam_tools.py pages   work/in/기출_2024_a.pdf --out work/exam/pages --grid 20 --pages 3,7-8   # 후보 쪽을 눈금과 함께 렌더 → 직접 본다
python3 kit/exam_tools.py crop    work/in/기출_2024_a.pdf --page 7 --box 2,6,11,12 --out work/exam/figs/24-1-17.png   # 눈금(0~20) 또는 비율(0~1)
#  … 배정표 work/exam/배정_기출_2024_a.tsv 를 쓴다. 첫 줄(탭 구분)은 글자 그대로:
#     파일	ID	시작줄	끝줄	교수 원표기	교수 정리	정리 근거	주제	공통	복기본	재출제	배정 근거	그림
python3 kit/exam_tools.py stems   work/exam/배정_*.tsv --text 기출_2024_a=work/exam/기출_2024_a.txt --out work/exam/stems.tsv   # 재출제 후보 찾기
# 첫 정리
python3 kit/exam_tools.py assemble --subject [과목] --out work/exam/out --index work/exam/배정_기출_2024_a.tsv --text 기출_2024_a=work/exam/기출_2024_a.txt --figs work/exam/figs --figpdf "work/exam/out/기출그림_[과목].pdf"
# 두 번째부터: 이번 배정표에 나온 주제의 기존 기출_[과목]_[주제].md · 색인 · 미분류를 지식에서 내려 work/exam/out 에 둔 뒤
python3 kit/exam_tools.py assemble --subject [과목] --out work/exam/out --index … --text … --figs work/exam/figs --figpdf "work/exam/out/기출그림_[과목].pdf" --prev-figpdf "work/in/기출그림_[과목].pdf" --append
```
`assemble` 출력(대조 보고 · 그림 수 · 주제별 표 · ✗)을 채팅에 그대로 옮긴다. 출력 폴더의 md 파일을 지식 `기출/`에 쓰고, `기출그림_[과목].pdf`를 제시한다.
