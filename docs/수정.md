## 부록 B 중 「이미지가 든 파일 수정(`lite_edit.py`)」

**이미지가 든 파일 수정(`수정` · 기출 카드 추가 — `lite_edit.py`)** — 이미지가 든 파일(수 MB)은 통째로 읽거나 고칠 수 없으므로 이 순서로만 고친다.
```
# 0) 첨부된 Part를 작업 폴더로 복사
cp "[첨부 Part].html" work/out/
# 1) 이미지를 뗀 작업 사본 만들기 + 절 목록 · meta · 기출 카드 · 기출 그림 수 보기
python3 kit/lite_edit.py strip work/out/[과목]_[강의명]_Part1_p1-12.html
#    → work/out/_lite/[…]_Part1_p1-12.lite.html  ← 이 사본만 Read · Edit 한다
# 2) 이미지 되붙이기 + 변경 검사 (처음 원본은 _lite/….before.html 로 보관된다)
python3 kit/lite_edit.py restore work/out/[과목]_[강의명]_Part1_p1-12.html
# 3) core 다시 만들기 (이미 빌드된 파일이라 테마를 다시 씌우지 않고 이미지도 그대로 둔다)
python3 kit/build_part.py work/out/[과목]_[강의명]_Part1_p1-12.html
```
- `restore` 출력 예: 「복원 완료 · 3.1 MB · 이미지 13/13」 / 「변경 검사 (기준: 처음 원본): 줄 추가 n · 줄 안 끼워 넣기 m · 기존 글자 바뀐 줄 2 (예상 2 · 그 밖 0) · 지운 줄 0」 / 「기출 카드 0 → 3 (새: …) · 중복 id 0 · 끊긴 링크 0」. 채팅에 그대로 옮긴다.
- 「그 밖」이나 「지운 줄」이 0이 아니거나 이미지 수가 다르면(종료 코드 1) 기존 본문을 건드린 것이다. 사본을 고쳐 다시 `restore` 한다. 제시하지 않는다.
- `strip`이 "고치던 사본이 원본보다 새것"이라며 멈추면 고치던 내용이 있다는 뜻이다. 먼저 `restore` 한다(버려도 될 때만 `--force`).
- `_lite/` 폴더의 파일은 제시하지 않는다.
